TEAL PERFUMES — SITE
=====================

Arquivos:
- index.html — site completo, responsivo e interativo
- logo.png — logo fornecido

Como usar:
1. Abra index.html em um navegador.
2. Para publicar, envie index.html e logo.png para seu host.
3. Os botões de Instagram, Linktree e Shopee já apontam para os endereços fornecidos.

Observação:
O catálogo e os preços foram estruturados a partir do PDF fornecido pela Teal Perfumes.
